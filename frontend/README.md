# Sistema de Gestão de Pessoas - Frontend

This repository contains the frontend foundation for the "Sistema de Gestão de Pessoas" project.

Key technologies:
- React + TypeScript
- Vite
- TailwindCSS
- React Router
- Axios

Getting started:
1. Copy `.env.example` to `.env` and set VITE_API_BASE_URL
2. npm install
3. npm run dev

Project structure highlights:
- src/core: shared components, hooks, contexts and lib
- src/layouts: application layouts
- src/pages: base pages (Welcome)
- src/features: add domain-specific features here (not included in foundation)

This foundation provides:
- Application bootstrapping
- Basic routing
- Global layout and components
- API client configuration
- Styling via Tailwind
- Error boundary and global providers
